Sobre las fórmulas de 1RM

El cálculo de la repetición máxima (1RM) es una estimación del peso máximo que puedes levantar en una repetición para un ejercicio. Se utilizan diferentes fórmulas para calcularlo, siendo las más comunes:

  • Epley: Usa repeticiones bajas a moderadas, ideal para ejercicios generales.
  • Brzycki: Precisa para repeticiones entre 1 y 10, ampliamente utilizada.
  • Lombardi: Diseñada para repeticiones altas (más de 10).
  • Mayhew: Específica para el press de banca.
  • McGlothin: Funciona bien para entrenamientos de fuerza generales.
  • O'Conner: Simple y efectiva para principiantes.
  • Wathan: Muy precisa para atletas avanzados.
